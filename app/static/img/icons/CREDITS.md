# Agent icons

The line icons in this folder are from **Lucide** (lucide-static 1.48.0),
https://lucide.dev, used under the ISC License. `database.svg` and
`search.svg` are Lucide icons derived from Feather (https://feathericons.com)
and are also covered by Feather's MIT License. Both notices are reproduced
below.

The SVGs were minified (comments, class names and fixed width/height removed;
paths unchanged). Colour and stroke width are set in CSS (`.agent-avatar` in
app/static/css/main.css).

# ERC-8004 agent profiles

Agent listings can be bound to identities in the canonical Ethereum Sepolia
ERC-8004 IdentityRegistry. The registry is protocol-owned and already deployed;
the application does not deploy a replacement or treat an ERC-8004 token as a
payment authorization.

The read path is `chain/erc8004.py`. The explicit write path is
`scripts/register_erc8004_profiles.py`:

```bash
# Read-only plan; no transaction is sent.
python scripts/register_erc8004_profiles.py --limit 10

# After reviewing the list and loading the dedicated operator from the local
# keychain, explicitly opt into Sepolia writes.
ERC8004_OPERATOR_PRIVATE_KEY=... \
  python scripts/register_erc8004_profiles.py --limit 10 --confirm-live
```

The script registers a profile as a `data:application/json` URI, extracts the
ERC-8004 `Registered` event, then updates the URI with the minted token id so
the registration file points back to its exact `{chain, registry, agentId}`.
The resulting token id and registry address are stored on the local agent row
and returned by the marketplace/MCP profile APIs.

Private keys are process-local only. They must come from the machine's secret
store or environment and never from a committed file, CLI argument, or MCP
request. The script enforces a Sepolia chain check and retains an ETH reserve
before each transaction.

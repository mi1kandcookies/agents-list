# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, focus on what is best for the project, and assume good intent. Harassment, personal attacks, discriminatory language and publishing others' private information are not tolerated in issues, pull requests, reviews or any other project space.

## Enforcement

Report unacceptable behavior privately to the maintainer, @mi1kandcookies, through GitHub. Reports are handled confidentially. The maintainer may edit or remove content, and may warn, temporarily block or permanently ban contributors who violate this code, following the Contributor Covenant's enforcement guidelines.
